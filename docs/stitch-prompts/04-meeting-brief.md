# Stitch prompt: Meeting detail + AI brief

**Purpose:** The magic moment. Paste a transcript → 20 seconds later, a polished brief. Exec reviews and approves.

**User goal:** Review, edit a line or two, approve, and move on.

---

## Paste this into Stitch

```
Design the meeting detail page for Workforce0 — the screen where a product
leader reviews an AI-generated brief from a meeting transcript.

Layout: two-pane split, 40/60.

Top header (spans both panes):
- Breadcrumb: Meetings / "Q3 Planning with Engineering"
- Right-aligned: status pill ("Draft", "Awaiting approval", "Approved"),
  ellipsis menu (Rename, Delete, Download .docx, Download .pdf).

Left pane (40%) — Source transcript:
- Small heading "Transcript" with word count.
- Scrollable text area with paragraph breaks and speaker labels
  (e.g., "Priya:", "David:"). Monospace-ish but readable.
- Top-right of this pane: a dropdown "Source: Pasted on Apr 18, 2:14 PM"
  (alternatives: Uploaded file, Google Meet, Phone dial-in).

Right pane (60%) — AI brief:
- Small generation status bar: "Generated by Gemini + Claude • 18s • $0.04".
- Large editable heading at top ("Q3 Planning with Engineering — Product
  Brief") — inline edit on click.
- Collapsible sections, each with a small icon and left-aligned expand
  arrow. Default open:
  - **Summary** (3–5 sentences)
  - **Decisions made** (bulleted list)
  - **Action items** (task cards: owner avatar, description, due-by pill,
    status "Pending")
  - **Requirements** (numbered list)
  - **Open questions** (bulleted, each with a small warning icon)
  - **Risks** (bulleted, severity pill)
- Each section has a small "Edit" pencil on hover.

Right pane sticky footer (always visible while scrolling):
- Left: "AI confidence: 88%" with a thin bar.
- Right: "Request changes" (ghost button), "Approve & push to Jira"
  (primary indigo, with a tiny Jira logo).
- When the user clicks the primary button, show a modal:
  "Push this brief to Jira?" with a dropdown to pick project, a preview
  of how many tickets will be created, and a "Push" button.

Loading state (first 20 seconds after paste):
- Right pane shows skeleton placeholders for each section.
- Above the skeleton: a calm loading message that updates: "Reading
  transcript…" → "Drafting with Gemini…" → "Critiquing with Claude…"
  → "Almost done…"

Tone: the AI is a helpful junior PM. Confident but never condescending.
Uses the exec's words where possible. Flags uncertainty clearly with
"This needs your input:" callouts instead of hiding gaps.
```

---

## Expected outputs

- Loaded state (brief ready)
- Loading / generating state
- "Approve & push to Jira" modal
- Mobile reflow — panes stack (brief on top, transcript below)

## Implementation notes

- Route: `frontend/src/app/(dashboard)/meetings/[id]/page.tsx`
- Streaming: use SSE to stream brief generation token-by-token
- "AI confidence" maps to Council consensus score from `ModelRegistryService`
- The "Request changes" path kicks off a new generation with the user's feedback as additional context
